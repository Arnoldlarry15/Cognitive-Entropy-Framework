## 1. Executive Summary & Diagnostic Scope

> [!IMPORTANT]
> **Diagnostic Purpose of the Pilot:**
> The pilot study is **NOT** the formal reliability benchmark, and it does **NOT** attempt to prove that Cognitive Entropy ($E_c$), Decision Overhead ($D$), or Intent Deviation ($N$) are valid cognitive constructs.
> 
> The pilot exists strictly to:
> 1. Discover operational rubric ambiguities and evidence deficits.
> 2. Test whether independent annotators can consistently apply non-causal observational rules.
> 3. Evaluate whether Event, Action, or Episode granularity is most appropriate for Intent Deviation ($N$).
> 4. Refine the protocol before freezing the official reliability benchmark dataset.

---

## 2. Pilot Study Design & Sample Plan

### 2.1 Sample Size & Task Classes

The pilot is intentionally compact and diverse, covering **12 recorded interaction sessions** across **3 distinct task classes**:

| Task Class | Session Count | Target $D$ Points | Target $N$ Units | Description / Scope |
| :--- | :---: | :---: | :---: | :--- |
| **Local Web Development** | 4 | ~15 | ~35 | Local coding, git commit, build script execution, bug fixing. |
| **Cloud Deployment** | 4 | ~25 | ~45 | Deploying static site via CLI/Web Console, OAuth login, DNS setup. |
| **Research & Literature Capture** | 4 | ~15 | ~35 | Literature search, PDF capture, note synthesis, citation formatting. |
| **Total Pilot Yield** | **12** | **~55** | **~115** | *Sufficient for initial diagnostic confusion matrix generation.* |

### 2.2 Annotators & Independence Rules
- **Annotators:** 3 independent trained annotators (Annotator A, Annotator B, Annotator C).
- **Blinding Protocol:** Double-blind independent annotation.
  - Annotators receive $I_{\text{task}}$, video playback, and telemetry logs.
  - Annotators **NEVER** see each other's ratings or confidence scores.
  - Annotators **NEVER** see participant self-report or demographic data.

---

## 3. Training & Qualification Procedure

1. **Calibration Package:** 20 pre-analyzed practice interaction sessions with gold-standard rationale notes.
2. **Qualification Threshold:** Trainees must achieve $\kappa_{\text{substantive}} \ge 0.80$ against calibration ratings on a 10-session practice test before proceeding to pilot data.
3. **Permanent Exclusion Rule:** All training and calibration data are permanently tagged as `TRAINING_DATA` and excluded from all evaluation statistics.

---

## 4. Workflow & Technical Data Locking

```
[ Session Recording + Pre-Declared I_task ]
                    │
                    ▼
    [ Isolated Annotator Workstation ]
 (Annotators A, B, C rate independently)
                    │
                    ▼
     [ Immutable Data Locking ]
 (initial_ratings written to frozen schema)
                    │
                    ▼
    [ Dual Reliability Math Engine ]
 (κ_substantive, κ_evidence, Gwet's AC1, CIs)
                    │
                    ▼
     [ Post-Rating Adjudication ]
 (Categorize disagreement reasons & store audit)
```

1. **Locking Initial Ratings:** Upon submission, ratings are stored as immutable `AnnotationItemRecord` instances (`initial_ratings`).
2. **No Retroactive Edits:** Annotators may never edit their `initial_ratings` after locking.
3. **Adjudication:** Post-rating adjudication creates an `AdjudicationRecord` containing `final_resolution` and `adjudication_reason`.

## 5. Statistical Analysis & Reliability Metrics

The pilot analysis computes and reports:

1. **Substantive Reliability ($\kappa_{\text{substantive}}$):** Cohen's $\kappa$ computed strictly on items where both annotators marked substantive categories (excluding `INSUFFICIENT_EVIDENCE`).
2. **Evidence Sufficiency Reliability ($\kappa_{\text{evidence}}$):** Binary agreement on whether items provided sufficient evidence.
3. **Prevalence-Robust Reliability (Gwet's AC1):** Diagnostic calculation of Gwet's AC1/AC2 alongside Cohen's $\kappa$.
4. **Multi-Rater Reliability (Fleiss' $\kappa$):** Fleiss' $\kappa$ across all 3 annotators.
5. **Full Diagnostic Matrix:**
   - Raw agreement $P_o$ & Expected agreement $P_e$.
   - 95% Confidence Intervals ($\text{CI}_{95\%}$).
   - Full $K \times K$ confusion matrices for $D$ and $N$.
   - Category marginal frequencies.

### 5.1 Granularity Multi-Criteria Evaluation ($N$)
Intent Deviation ($N$) will be evaluated at **Event**, **Action**, and **Episode** granularities across 6 weighted criteria:
1. Substantive Reliability ($\kappa_{\text{substantive}}$)
2. Theoretical Coherence (alignment with goal-directed behavior)
3. Temporal Meaning (preservation of duration boundaries)
4. Evidence Requirements (observational feasibility)
5. Category Prevalence (avoiding extreme category skew)
6. Reproducibility Across Annotator Cohorts

## 6. Disagreement Diagnostics & Rubric Revision Trigger

When annotator ratings differ, the adjudication team categorizes the root cause using the 6-type taxonomy:

```python
class DisagreementReason(Enum):
    DEFINITION_AMBIGUITY = "DEFINITION_AMBIGUITY"
    EVIDENCE_DEFICIT = "EVIDENCE_DEFICIT"
    ANNOTATOR_DISAGREEMENT = "ANNOTATOR_DISAGREEMENT"
    BEHAVIORAL_AMBIGUITY = "BEHAVIORAL_AMBIGUITY"
    ANNOTATOR_ERROR = "ANNOTATOR_ERROR"
    TASK_CONTEXT_EFFECT = "TASK_CONTEXT_EFFECT"
```

### Rubric Revision Triggers
A formal rubric revision is triggered if:
- $\kappa_{\text{substantive}} < 0.80$ on the pilot dataset.
- Any single off-diagonal cell in the confusion matrix accounts for $>15\%$ of total items.
- More than $20\%$ of items are marked `DEFINITION_AMBIGUITY` or `EVIDENCE_DEFICIT`.

## 7. Official Benchmark Freeze Criteria

The protocol is considered ready for the formal reliability benchmark ONLY when all of the following project governance criteria are satisfied:

- [ ] **Rubric Clarity:** Zero unresolved major category definition ambiguities in the Borderline-Case Library.
- [ ] **Evidence Sufficiency:** Less than $10\%$ of items in the pilot dataset marked `INSUFFICIENT_EVIDENCE`.
- [ ] **Reliability Gate:** Pilot achieves $\kappa_{\text{substantive}} \ge 0.80$ (with lower bound of $\text{CI}_{95\%} \ge 0.70$) and Gwet's $\text{AC}_1 \ge 0.80$.
- [ ] **Granularity Stability:** Final unit of analysis for $N$ (Event, Action, or Episode) formally selected based on multi-criteria evaluation.
- [ ] **Provenance & Auditability:** 100% of pilot annotations traceable to immutable `initial_ratings` and pre-declared $I_{\text{task}}$ records.
