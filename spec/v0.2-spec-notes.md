## 1. Epistemic Boundary & Methodological Note

> [!IMPORTANT]
> **Candidate Signals vs. Validated Measurements:**
> Telemetry events logged by software listeners represent **candidate telemetry signals**, not validated cognitive or coordination measurements. 
> The ability to parse an event log (e.g., counting window context switches) does not automatically establish that the log faithfully quantifies cognitive entropy. 
> Signal extraction ($v0.2$) is explicitly decoupled from baseline adjustment ($v0.4$) and construct validation ($v0.5$).

---

## 2. Telemetry Log Format (`telemetry_event.jsonl`)

Interaction sessions are logged as a stream of line-delimited JSON objects. Every event conforms to the following structural schema:

```json
{
  "timestamp": "2026-08-10T12:00:00.000Z",
  "session_id": "sess_98765",
  "event_type": "environment_switch | interaction | interruption | decision | note",
  "source_app": "VSCode",
  "target_app": "AWS Console",
  "environment_id": "env_aws_cloud_console",
  "action": "click | keystroke | window_focus | popup_spawn | oauth_prompt",
  "metadata": {
    "dwell_time_ms": 4500,
    "is_system_initiated": true,
    "label": "MFA Challenge"
  }
}
```

## 3. Candidate Raw Signal Definitions

### 3.1 Raw Application Fragmentation Signal ($A_{raw}$)
* **Definition:** Count of unique digital environments entered during a task session.
* **Operational Boundary:** An environment context entry requires a focus dwell time $t_{\text{dwell}} \ge t_{\text{threshold}}$ (default: $2,000 \text{ ms}$). Brief focus ticks below this threshold are flagged as transient noise and excluded from $A_{raw}$.

### 3.2 Raw Context Transition Frequency Signal ($S_{raw}$)
* **Definition:** Rate of qualifying transitions between distinct cognitive environments per unit task time (transitions / minute).
* **Operational Boundary:** Transitions between tabs within the same continuous IDE or document context are excluded; only transitions between independent application boundaries qualify.

### 3.3 Raw Interruption Frequency Signal ($I_{raw}$)
* **Definition:** Rate of externally initiated workflow interruptions per unit task time (events / minute).
* **Qualifying Events:** System-spawned dialogs, CAPTCHAs, MFA prompts, forced updates, session expirations, and unrequested OS notification takeovers (`is_system_initiated == true`).

## 4. Decoupled Pipeline Architecture

In v0.2, the telemetry module acts strictly as an **unadjusted signal extractor**:

```
[ Raw Telemetry Stream (.jsonl) ] 
               │
               ▼
   [ TelemetryParser (v0.2) ] 
               │
               ▼
[ Raw Signals: A_raw, S_raw, I_raw ] 
               │
               ▼  (v0.4 Baseline Adjustment)
[ Baseline-Adjusted Excess Variables x_i ] 
               │
               ▼  (v0.5 Weighted Model)
   [ Ec Functional Score Calculation ]
```
